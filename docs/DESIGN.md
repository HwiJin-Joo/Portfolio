# DESIGN.md — 주휘진 포트폴리오 (v2 / 3페이지 구조)

v1(단일 페이지·라이트 기본) 폐기. 이 문서가 유일한 규격이다.

## 1. 목적

- **페이지 종류** 개인 포트폴리오. 3페이지 정적 사이트
- **타깃** 게임사 채용 담당자. 시스템 / 콘텐츠 / UX 기획 직무를 함께 본다
- **첫 화면 한 문장** "끝까지 만들어본 게임 기획자"
- **제약** GitHub Pages 정적 배포 · 다크 온리 · 모바일 대응 필수 · 외부 JS 라이브러리 없음
- **구조**
  | 파일 | 역할 |
  |---|---|
  | `index.html` | 프로젝트 정보 · 주요 업무 · 성과를 스크롤만으로 전부 |
  | `beastblood.html` | 18건 업무 이력. 카테고리 5개 |
  | `nomanual.html` | 9건 업무 이력. 카테고리 4개 |
  | `style.css` / `app.js` | 3페이지 공용 |

## 2. 컬러

다크 온리. 라이트 대응 없음.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#08090B` | 페이지 배경 |
| `--bg-2` | `#0D0F13` | 카드·미디어 배경 |
| `--panel` | `#101319` | 연락처 카드 |
| `--fg` | `#F4F5F7` | 본문 |
| `--fg-mid` | `#A9AFBA` | 보조 본문 |
| `--fg-dim` | `#767E8B` | 라벨·캡션 |
| `--line` | `rgba(255,255,255,.08)` | 기본 구분선 |
| `--line-2` | `rgba(255,255,255,.14)` | 강조 보더 |
| `--accent` | `#FF4B33` | 강조 1개만 |
| `--on-accent` | `#0A0B0D` | 강조색 위 글자 |
| `--surface-1` | `rgba(255,255,255,.02)` | 스킬 태그 배경 |
| `--accent-soft` | `rgba(255,75,51,.14)` | 활성 칩 배경 |

대비비 (실측):

| 조합 | 비율 | 판정 |
|---|---|---|
| `--fg` / `--bg` | 18.26:1 | AA · AAA |
| `--fg-mid` / `--bg` | 9.04:1 | AA · AAA |
| `--fg-dim` / `--bg` | 4.86:1 | AA |
| `--accent` / `--bg` | 5.98:1 | AA |
| `--on-accent` / `--accent` | 5.91:1 | AA |

`--fg-dim`은 캡션·라벨 전용. 12px 미만에는 쓰지 않는다.
강조색 위 글자는 흰색이 아니라 `--on-accent`. 흰색은 3.33:1로 AA 미달이다.

## 3. 타이포

```
"Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont,
system-ui, "Apple SD Gothic Neo", sans-serif
--mono: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace
```

| 역할 | 크기 | 행간 | 굵기 |
|---|---|---|---|
| h1 (index) | `clamp(38px,7vw,84px)` | 1.05 | 800 |
| h1 (상세) | `clamp(34px,5.4vw,60px)` | 1.05 | 800 |
| h2 섹션 | `clamp(24px,3vw,34px)` | 1.2 | 700 |
| h3 프로젝트명 | `clamp(24px,3.2vw,38px)` | 1.1 | 700 |
| h3 업무블록 | 21px | 1.35 | 700 |
| 리드 | `clamp(16px,1.6vw,20px)` | 1.6 | 400 |
| 본문 | 16px | 1.7 | 400 |
| 표 내용 | 14px | 1.65 | 400 |
| 라벨 (mono) | 10.5~12px | 1.4 | 500, letter-spacing .12~.16em, uppercase |

- 숫자는 `font-variant-numeric: tabular-nums`
- 본문 최대폭 **62ch**. 리드는 56ch
- mono는 라벨·기간·기술스택·수치에만. 본문에 쓰지 않는다

## 4. 간격

- 기본 유닛 **4px** — 모든 padding·gap·margin은 4의 배수
- 레이아웃 오프셋 토큰: `--nav-h:64px` `--tab-h:60px` `--pad:32px`(모바일 20px)
- 컨테이너 최대폭 **1160px**, 좌우 패딩 32px (모바일 20px)
- 섹션 간 **112px** (모바일 80px)
- 업무블록 간 **40px** + 상단 1px 구분선
- 카드 내부 패딩 **28~32px** (모바일 20~22px)

## 5. 컴포넌트

| 컴포넌트 | 규격 |
|---|---|
| 프로젝트 카드 | 라운드 18px, 1px `--line`, hover 시 `--accent` 보더 + `translateY(-3px)` |
| 업무블록 표 | 보더 없음. 행 상단 1px `--line`. 라벨 열 74px 고정 |
| 갤러리 figure | 라운드 12px, 1px `--line`, 큰 것 `16/10`, 작은 것 `4/3` |
| 탭 | pill 999px. 비활성 = 투명 + `--line`. 활성 = `--accent` 배경 |
| 칩 | 라운드 6px, 11px mono. 활성 칩만 `--accent-soft` |
| 스킬 태그 | pill 999px, 13px. 상위 3개만 강조색 |
| 버튼 | 라운드 8px. `.solid`는 `--accent` 배경 |
| 포커스 | `outline: 2px solid var(--accent); outline-offset: 3px` — 절대 제거 안 함 |
| 터치 타겟 | 모바일 최소 44×44px |

## 6. 레이아웃

**index.html**

0. 고정 상단 바 — 브랜드 / Work·Career·Contact / 경력기술서 CTA
1. 히어로 — 킥커 / h1 / 리드 / **스킬 태그 8개** / CTA 2개 / 프로필 사진(원형)
2. 지표 4열 — 완주 2개 · 업무 이력 27건 · 펀딩 287% · 데모 4챕터
3. `01 / WORK` — 프로젝트 카드 2장. 카드 하나에 **정보 + 주요 업무 4 + 성과 4**가 전부 들어간다. 카드 전체가 상세 페이지 링크
4. `02 / CAREER` — 회사 3곳 + 수상·수료
5. `03 / CONTACT` — 2×2 카드

**상세 페이지**

1. 페이지 헤더 — 뒤로가기 / 프로젝트명 / 장르 / 요약 4열(기간·역할·팀·엔진)
2. 카테고리 탭 — `position:sticky; top:64px`. 건수 배지. URL 해시 연동
3. 업무블록 반복 — 좌 표(기간·역할·성과·기술) / 우 갤러리(큰 1 + 작은 2)
   - 이미지 없는 블록은 `.solo`로 표를 전체폭 사용

브레이크포인트 **900px**(2컬럼 → 1컬럼) / **640px**(패딩·폰트 축소, 내비 축약)

## 7. 모션

- 대상: 색·보더·transform·opacity. `220ms cubic-bezier(.2,.7,.3,1)`
- 이미지 확대는 `700ms` 별도
- 스크롤 리빌 1회 (`IntersectionObserver`, 최대 3개씩 70ms 스태거)
- `prefers-reduced-motion: reduce` 시 전부 `0.01ms` + 리빌 즉시 표시

## 8. 안 하는 것

v1은 이 목록이 과해서 텍스트 문서가 됐다. 이번엔 **장식은 허용하고 남용을 막는다.**

- 강조색은 `--accent` **하나만**. 두 번째 색을 도입하지 않는다
- 그라디언트는 **이미지 위 오버레이와 히어로 앰비언트에만**. 버튼·카드 배경에 쓰지 않는다
- 그림자 금지. 깊이는 보더와 `translateY`로만
- 이모지 금지. 아이콘은 화살표(`→` `↗` `←`) 외 사용하지 않는다
- 캐러셀·아코디언 금지. 탭 필터 외 콘텐츠를 접지 않는다
- 외부 JS 라이브러리 금지 (폰트 CDN만 허용)
- 업무블록을 요약하지 않는다 — 27건 전부 싣고 필터로 좁힌다
- 성과 없는 항목은 넣지 않는다
- 회사 실수치는 블러 처리 후에만 노출한다
